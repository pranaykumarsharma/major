# 🚀 GitHub User Explorer


> A modern, responsive web application to search and explore GitHub user profiles with a visually striking Glassmorphism UI.

### 🌐 **View Live Demo** - https://githubuserexplorer-nine.vercel.app

---

## 📖 Overview

**GitHub User Explorer** is a web-based tool that interacts with the GitHub REST API to fetch real-time data. It allows users to search for any GitHub username and instantly view their profile details, statistics, and latest repositories. 

The project is built with a **mobile-first approach**, featuring a dynamic video background and a polished glassmorphism interface that looks professional on desktops, tablets, and mobile devices.

## ✨ Features

- **🔍 Smart Search:** Instantly find users by their GitHub username.
- **📊 User Statistics:** View followers, following, public repo counts, and bio.
- **📂 Repository Explorer:** Lists the latest 10 updated repositories with:
  - Star counts ⭐
  - Programming language indicators 🔵
  - Direct links to code 🔗
  - Last updated dates 📅
- **🎨 Modern UI/UX:**
  - Glassmorphism design (Blur effects & transparency).
  - Background video integration.
  - Smooth animations and transitions.
  - **Fully Responsive** (CSS).
- **⚠️ Error Handling:** Graceful error messages for empty inputs or non-existent users.
